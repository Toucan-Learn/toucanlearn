# Toucan Learn website v1

This is a single-page static landing site. Open `index.html` in a browser to view it.

## Edit these first

1. Replace every instance of:

`https://forms.gle/REPLACE_WITH_YOUR_FORM_LINK`

with your real Google Form intake link.

2. Replace placeholder reviews with real approved reviews.

3. Replace the case study placeholder with an anonymised example.

4. Update prices if needed.

## Suggested Google Form fields

- Parent/carer name
- Email
- Phone number
- Child's year group
- Main area of support needed
- SEN/additional needs context
- Current school concerns
- Preferred days/times
- Anything that helps the child engage

## How to publish quickly

Recommended easiest route:

1. Create a GitHub account if needed.
2. Create a new repository called `toucan-learn`.
3. Upload these files.
4. Go to Settings → Pages.
5. Set branch to `main` and folder to `/root`.
6. GitHub gives you a live link.

Alternative:

Use Netlify Drop: drag the folder into Netlify Drop and it gives you a live website link.
